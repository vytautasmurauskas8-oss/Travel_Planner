# Travel Planner – projekto idėja

## 1. Problema
Kelionių planavimas dažnai reikalauja naudoti kelias skirtingas platformas. Informacija apie kelionės datas, lankytinas vietas ir veiklas būna išskaidyta, todėl sunku patogiai valdyti visą kelionės planą.

## 2. Tikslinė auditorija
Savarankiškai keliones planuojantys žmonės, poros, šeimos ir draugų grupės.

## 3. Projekto tikslas
Sukurti paprastą ir patogią internetinę aplikaciją, kurioje vartotojai galėtų vienoje vietoje planuoti keliones, organizuoti veiklas ir valdyti savo kelionių planus.

## 4. Pagrindinės funkcijos
- Naujos kelionės sukūrimas.
- Kelionės šalies, miesto ir datų įvedimas.
- Kelionės dienų planavimas.
- Lankytinų vietų ir veiklų pridėjimas.
- Kelionių ir veiklų peržiūra, redagavimas bei ištrynimas.

## 5. Naudojamos technologijos
- React – vartotojo sąsajai.
- Vite – projekto kūrimui ir paleidimui.
- JavaScript – aplikacijos logikai.
- CSS – dizainui.
- Supabase – duomenų bazei.
- GitHub – versijų kontrolei.
- Cursor ir Codex – programavimui.
